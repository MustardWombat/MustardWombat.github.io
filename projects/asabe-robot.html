ASABE Agricultural Robotics Challenge Robot '26

Autonomous ground robot for precision crop scouting, weed detection, and field intervention

ROS2 C++ Python Autonomous Navigation Computer Vision Sensor Fusion
🚧 In Progress — Jan 2026 – Present

Project Overview

This is a year-long robotics engineering project building a fully autonomous ground robot for the ASABE Agricultural Robotics Challenge. The robot is designed to navigate agricultural fields autonomously, performing precision tasks including crop scouting, weed detection, and targeted field intervention.

The platform runs on ROS2, integrating GPS, IMU, and camera sensors through a custom navigation stack. My focus is on the low-level controls and sensor integration — translating sensor data into reliable robot behavior in real outdoor environments where GPS can be noisy and terrain is uneven.

This project is a step up in complexity from previous work: rather than adding autonomy to existing farm equipment, this is a purpose-built robot designed from the ground up for autonomous field operation.

System Architecture

📡 Sensing

  • RTK-GPS
    Centimeter-level outdoor positioning
  • IMU
    Orientation, heading, motion compensation
  • RGB Camera
    Crop row detection, weed identification
  • Wheel Encoders

💻 Compute & Control

  • ROS2 Navigation Stack
    Path planning, waypoint following
  • Sensor Fusion Node
    GPS + IMU + odometry EKF
  • Vision Pipeline
    OpenCV crop row and weed detection
  • Motor Controllers
    Closed-loop drive commands

⚙️ Actuation

  • Differential Drive
    Independent left/right motor control
  • Intervention Mechanism
    Precision weed targeting actuator

Control Flow

  1. Localization: EKF fuses RTK-GPS, IMU, and encoder odometry into a stable pose estimate
  2. Perception: Camera pipeline detects crop rows and flags weed locations in real time
  3. Planning: ROS2 nav stack generates paths through field waypoints, replanning around obstacles
  4. Control: Velocity commands drive differential motors with closed-loop feedback
  5. Intervention: On weed detection, robot halts and triggers targeted actuator

Challenges & Solutions

Reliable Localization in Outdoor Fields

Challenge: GPS alone is noisy and discontinuous. IMU drifts over time. Odometry accumulates error on rough terrain. None are reliable individually for precise field navigation.

Solution: Implemented an Extended Kalman Filter via ROS2's robot_localization package to fuse all three sources. Each sensor's covariance is tuned to reflect real-world noise characteristics, giving the filter a reliable continuous pose estimate even when individual sensors degrade.

ROS2 Team Coordination

Challenge: Multiple team members developing nodes concurrently leads to interface mismatches and integration bugs — especially when hardware is shared and testing time is limited.

Solution: Established a shared message type convention and topic naming standard early in development. Used Git branches per subsystem with integration testing sessions to catch interface issues before they compound.
