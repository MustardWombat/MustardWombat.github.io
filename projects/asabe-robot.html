ASABE Agricultural Robotics Challenge Robot '26

Autonomous ground robot for precision crop scouting, weed detection, and field intervention

ROS2 C++ Python Autonomous Navigation Computer Vision Sensor Fusion
🚧 In Progress — Jan 2026 – Present

Why

A year-long, ground-up build for the ASABE Agricultural Robotics Challenge. Unlike the autosteer project — which added autonomy to existing equipment — this is a purpose-built autonomous robot designed from scratch for real outdoor field operation: crop scouting, weed detection, and precision intervention.

My focus is low-level controls and sensor integration — translating noisy real-world sensor data (GPS dropouts, uneven terrain, IMU drift) into reliable robot behavior via a ROS2 navigation stack and EKF sensor fusion.

Control Flow

  1. Localize — EKF fuses RTK-GPS, IMU, encoders into stable pose
  2. Perceive — Camera detects crop rows and flags weed locations
  3. Plan — Nav2 routes through field waypoints, replanning around obstacles
  4. Drive — Velocity commands to differential motors via closed-loop feedback
  5. Intervene — On weed detection, halt and trigger actuator

Wrinkles

Reliable Outdoor Localization

Challenge — GPS alone is noisy. IMU drifts. Odometry accumulates error on rough terrain. None reliable individually.

Solution — EKF via robot_localization fuses all three, with per-sensor covariances tuned to real-world noise. Stable continuous pose even when individual sensors degrade.

Multi-Developer ROS2 Integration

Challenge — Concurrent subsystem development causes topic/interface mismatches when hardware is shared and test time is scarce.

Solution — Established shared message type conventions and topic naming standards early. Git branches per subsystem with scheduled integration sessions.
