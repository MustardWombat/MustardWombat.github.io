MMPose HPCC Pipeline

A full end-to-end animal pose estimation pipeline built for MSU's High-Performance Computing Cluster (HPCC), with a browser-based web UI for non-technical users.

MMPose PyTorch HRNet Gradio SLURM Python HPCC

Why This Project Matters

A research-grade computer vision pipeline for bottom-up pig pose estimation, developed at MSU's SMARTS lab. The system takes images or video of piglets and predicts the locations of 7 anatomical keypoints — Snout, Head, Shoulder, Back, Tail, Left Ear, Right Ear — drawing a labeled skeleton overlay on the output.

It is designed to run on both local machines and SLURM-managed GPU cluster nodes, and includes a Gradio web UI (~2,400 lines) accessible remotely via SSH port forwarding for non-technical researchers.

Which Tools & Stack

Model Architecture

  • BottomupPoseEstimator with HRNet-W32 backbone (pretrained on ImageNet)
  • 4 multi-resolution stages producing feature maps at 32/64/128/256 channels
  • FeatureMapProcessor neck (feature concatenation → 480ch)
  • DEKRHead for simultaneous heatmap and displacement field prediction
  • SPR codec — 512×512 input, 128×128 heatmap output
  • Mixed-precision training support (--amp)

Stack & Infrastructure

  • MMPose (OpenMMLab) + MMEngine + PyTorch
  • COCO keypoint JSON (Roboflow export format)
  • Roboflow Python SDK for dataset management
  • SLURM sbatch — 1 GPU, 8 CPUs, 32 GB RAM, up to 24h jobs
  • Python venv / Conda (openmmlab env)

Workflow Features

  • PigDataset7kpts — Custom MMPose dataset class with per-keypoint OKS sigmas and a category_id int-coercion fix for Roboflow COCO exports.
  • run_image_overlay.py — Single image or video inference with OpenCV skeleton overlay. Keypoint/skeleton topology is read from the COCO training JSON to guarantee index ordering matches the trained model.
  • batch_predict.py — Batch inference over image folders; outputs COCO-format JSON with per-instance visibility scores. Supports direct re-upload to Roboflow for active learning loops.
  • app.py (Gradio Web UI) — Five tabs: Instructions, Dataset Downloader (Roboflow API), Training (sbatch generation + live log streaming), Batch Annotate, and single-image Inference with score threshold control.

Wrinkles We Solved

PYTHONPATH Package Shadowing

Problem: Both the repo root and the cloned MMPose submodule were on the path, causing the nested mmpose package to shadow the installed one at import time.

Solution: Explicit PYTHONPATH manipulation at import time to enforce correct resolution order.

MMEngine Config Inheritance Bug

Problem: MMEngine's _base_ config inheritance triggers NoneType merge failures when validation dataloaders are disabled.

Solution: Runtime config patching via regex text substitution instead of MMEngine's inheritance system, applied dynamically by the Web UI when generating training configs.

Keypoint Index Consistency

Problem: Sourcing skeleton topology from dataset_meta at inference time could produce index mismatches relative to training data.

Solution: Skeleton topology is always sourced directly from the COCO annotation JSON used during training, guaranteeing consistent keypoint ordering across all inference tools.
