Project Overview

Developed a fully integrated autonomous steering system for an agricultural cultivator, combining Jetson Nano, stereo camera vision, Python, ROS2 nodes, and a servo motor for actuation. The system uses vision-based lane guidance: stereo camera and Jetson Nano perform real-time image processing to calculate cross-track error (XTE), ROS2 nodes handle control logic, and a servo motor provides precise steering. System-level integration of perception (vision-based XTE), control (PID loop), and actuation (PWM to servo) enables robust center line following and real-time correction. Hardware and software interfaces are coordinated across power, compute, sensing, and mechanical subsystems to deliver a cohesive autonomous platform.

Auto-Steering Cultivator: Technical Details

  • Frame extraction pipeline running on NVIDIA Jetson Nano, using a model framework and confidence measure to identify and extract low-confidence frames for dataset improvement.
  • PID control loop for servo motor: takes cross-track error (XTE) and computes desired steering angle, converts to PWM signal for servo actuation.
  • Physical system includes a shaft coupler connecting the servo to the cultivator steering mechanism for precise center line following.
  • Closed-loop system enables real-time correction and robust center line tracking in field conditions.
  • Continuous dataset improvement through automated low-confidence frame extraction and annotation.
